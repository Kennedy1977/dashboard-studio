Orbit Dashboard Studio

Build your first dashboard.

Follow the steps below to understand, copy and connect every reusable widget in this project.

Live examples: See every component rendered with working HTML on the live examples page ↗.
01

Get started

Run a local server from the project folder so the browser can load the guide and ES modules.

python3 -m http.server 4173

Open http://127.0.0.1:4173.

02

Use the widget contract

Every widget receives the same ID, title, config, data, filters and lifecycle state.

createWidget({ id: 'revenue', title: 'Revenue', config: { adapter: 'svg-line' }, data: { labels: ['Jan', 'Feb'], values: [12, 18] }, filters: {}, isLoading: false, error: null });
03

Add metric widgets

Use metrics for a single number. Use a gauge or progress bar when the number has a target.

{ "type": "metric", "data": { "value": 18294, "delta": 8.2 } }
{ "type": "gauge", "data": { "value": 78, "target": 100 } }
See live metric examples ↗
04

Choose a chart

Line and area show trends. Bar compares categories. Donut shows part-to-whole. Heatmap shows intensity. Scatter shows relationships.

{ "type": "line", "data": { "labels": ["Jan", "Feb"], "values": [22, 31] } }
{ "type": "donut", "data": { "labels": ["Organic", "Direct"], "values": [42, 28] } }
See live chart examples ↗
05

Add controls and filters

Use text inputs, selects, checkboxes, radio buttons, toggles and ranges. Send shared filters through the dashboard bus.

setFilters({ dateRange: 'last-7-days', region: 'north' });
dashboardBus.on('filters:change', ({ detail }) => reloadAllWidgets(detail));
See live control examples ↗
06

Show records and people

Use tables for records, timelines for history, and profile cards for owners or customers.

{ "type": "table", "config": { "pageSize": 10, "sortable": true } }
{ "type": "profile", "data": { "name": "Andrew Kennedy", "role": "Frontend developer" } }
See live record examples ↗
07

Handle loading and errors

Show a skeleton while loading, a CTA when empty, and a retry action when a request fails.

createWidget({ id: 'forecast', isLoading: true });
createWidget({ id: 'forecast', data: [], error: new Error('Request failed') });
08

Add your own widget

  1. Add metadata to widgetCatalog.
  2. Define normalized data.
  3. Create an adapter or renderer.
  4. Add layout/config to dashboard-config.json.
  5. Add lifecycle states and a live example.
