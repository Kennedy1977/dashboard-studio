Widget guide.

A simple reference for understanding, copying and connecting every dashboard component in the project.

Start here

Run the guide

From the project folder, run a local server:

python3 -m http.server 4173 | http://127.0.0.1:4173/ | http://127.0.0.1:4173/guide.html
Foundation

Universal widget contract

Every widget receives an ID, title, configuration, data, filters and lifecycle state.

createWidget({ id: 'revenue', title: 'Revenue', config: { adapter: 'svg-line' }, data: { labels: ['Jan', 'Feb'], values: [12, 18] }, filters: { dateRange: 'last-30-days' }, isLoading: false, error: null });
01 / Metrics

KPI, delta, sparkline and gauge

Use KPI cards for a single important value. Add a delta for comparison, a sparkline for direction, or a gauge for target progress.

{ "type": "metric", "data": { "value": 18294, "delta": 8.2, "trend": [12, 18, 15, 24] } } | { "type": "gauge", "data": { "value": 78, "target": 100 } }
02 / Charts

Line, area, bar, donut, heatmap and scatter

Line and area show trends, bar compares categories, donut shows part-to-whole, heatmap shows intensity, and scatter shows relationships.

{ "type": "line", "config": { "area": true }, "data": { "labels": ["Jan", "Feb"], "series": [{ "name": "Revenue", "values": [22, 31] }] } } | { "type": "donut", "data": { "labels": ["Organic", "Direct"], "values": [42, 28] } } | { "type": "scatter", "data": { "points": [{ "x": 12, "y": 18 }] } }
03 / Records

Tables, lists and timelines

Use tables for searchable records, lists for compact activity, and timelines for chronological history.

{ "type": "table", "config": { "pageSize": 10, "sortable": true }, "data": { "columns": ["customer", "status"], "rows": [] } } | { "type": "timeline", "data": { "items": [{ "time": "09:42", "title": "Import complete" }] } }
04 / Controls

Inputs, filters and shared state

The dashboard includes text inputs, selects, radio buttons, checkboxes, toggles and range sliders.

setFilters({ dateRange: 'last-7-days', region: 'north' }); dashboardBus.on('filters:change', ({ detail }) => reloadAllWidgets(detail));
05 / People

Profile / contact card

Use this for account owners, team members, customers or assignees.

{ "type": "profile", "data": { "name": "Andrew Kennedy", "role": "Frontend developer", "status": "online" } }
06 / Lifecycle

Loading, empty and error states

Show a skeleton while loading, a useful CTA when empty, and a retry action when a request fails.

createWidget({ id: 'forecast', isLoading: true }); | createWidget({ id: 'forecast', data: [], error: new Error('Request failed') });
07 / Extend

Add a new widget

  1. Add metadata to widgetCatalog.
  2. Define normalized data.
  3. Create an adapter or renderer.
  4. Add layout/config to dashboard-config.json.
  5. Add loading, empty and error states.
  6. Add the example to WIDGET-GUIDE.md and this page.
