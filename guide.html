Orbit Dashboard Studio

Build your first dashboard.

Each example is shown on the page first, followed by the markup to copy. This is the same learn-by-example pattern used by component documentation sites.

Try it: change the values in the examples, copy the markup, and paste it into your own widget.

06

Loading, empty and error states

Show a skeleton while loading, a CTA when empty, and a retry action when a query fails. Keep errors isolated to the widget.

createWidget({ id: 'forecast', isLoading: true });
createWidget({ id: 'forecast', data: [], error: new Error('Request failed') });
